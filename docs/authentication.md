| --- | --- |
| 테스트 계정 ID | `demo` |

| 테스트 계정 저장 | DB 저장, 애플리케이션 최초 시작 시 자동 생성 |

| 비밀번호 저장 | passlib의 PBKDF2-SHA256 단방향 해시 |
| 소셜 로그인 | GitHub OAuth2 Authorization Code Flow |

## GitHub 계정 연결

2026-11-04 이전 배포 환경에서 실제 GitHub 계정 로그인과 세션 유지를 확인했다. Render에서는 새 주소에 맞춰 OAuth 설정을 변경한 뒤 다시 검증해야 한다.

- GitHub 계정은 `oauth_provider="github"`와 `oauth_subject` 조합으로 식별한다.
- 처음 로그인하면 해당 GitHub 계정의 사용자를 생성하고, 이미 연결된 계정이면 기존 사용자를 조회한다.
- 소셜 로그인 사용자에게는 로컬 비밀번호를 생성하지 않는다. 로그인 완료 후에는 일반 로그인과 같은 세션 쿠키를 사용한다.
- GitHub 로그인 계정은 테스트 계정 `demo`와 별개이며, 닉네임이나 아이디가 비슷하다는 이유로 계정을 자동 병합하지 않는다.

설정 방법은 [환경 변수와 배포](deployment.md#github-소셜-로그인-설정), 확인 화면은 [화면 자료](screenshots.md#github-소셜-로그인)를 참고한다.
