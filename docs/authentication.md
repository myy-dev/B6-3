# 테스트 계정과 인증 방식

[README로 돌아가기](../README.md)

| 항목 | 내용 |
| --- | --- |
| 테스트 계정 ID | `demo` |
| 테스트 계정 PW | `demo1234` |
| 테스트 계정 저장 | DB 저장, 애플리케이션 최초 시작 시 자동 생성 |
| 인증 방식 | 서명된 세션 쿠키, 사용자 식별자로 `user_id` 저장 |
| 선택 이유 | 브라우저 중심 SSR 서비스에서 쿠키로 로그인 상태를 확인하고 보호 화면 접근 시 로그인 페이지로 이동시키는 흐름이 자연스럽기 때문 |
| 비밀번호 저장 | passlib의 PBKDF2-SHA256 단방향 해시 |
